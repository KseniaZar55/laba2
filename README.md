# CINÉ CLUB — GitHub Pages version

Статический сайт-подборщик фильмов на HTML, CSS и JavaScript. Работает на GitHub Pages без Python, сервера и установки библиотек. Данные фильмов загружаются из OMDb API.

## Запуск локально

Можно просто открыть `index.html` в браузере. Для более надёжной работы открой папку в VS Code и запусти расширение Live Server.

## Подключение OMDb API

1. Получи бесплатный ключ: https://www.omdbapi.com/apikey.aspx
2. Открой сайт и вставь ключ в панель подключения вверху страницы.
3. Нажми «Подключить». Ключ сохраняется только в `localStorage` этого браузера, а не в файлах проекта.
4. При публикации на GitHub Pages введи ключ на опубликованном сайте один раз.

**Важно:** статический сайт обращается к OMDb напрямую из браузера. Ключ не попадает в репозиторий, но пользователь, который откроет DevTools, теоретически сможет увидеть его в сетевом запросе. Не используй здесь секреты или платный ключ с ценными квотами. Для учебного проекта используй бесплатный ключ и не публикуй его в исходном коде.

## Публикация именно на GitHub Pages

1. Создай новый репозиторий на https://github.com/new.
2. Распакуй ZIP и загрузи **содержимое папки** в корень репозитория: `index.html`, `app.js`, `style.css`, `github.css`, `README.md`.
3. Открой репозиторий → **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/(root)`, нажми **Save**.
6. Подожди, пока GitHub опубликует сайт, затем открой адрес, показанный в Settings → Pages.
7. Введи OMDb API key в панели подключения на опубликованном сайте.

Все пути в проекте относительные (`./style.css`, `./app.js`), поэтому сайт подходит для репозитория GitHub Pages, в том числе по адресу вида `username.github.io/repository-name/`.

## Что умеет

- Подборка из трёх фильмов на основе поиска OMDb.
- Поиск по названию/ключевому слову.
- Фильтр по жанру (OMDb не имеет отдельного API каталога по жанрам, поэтому сайт получает результаты поиска и фильтрует данные жанров).
- Кнопки «Да» и «Нет».
- Избранное и пропущенные фильмы хранятся в `localStorage`.
- Адаптивный интерфейс и тот же тёмный дизайн с лаймовым акцентом.

## Ограничения OMDb

У бесплатного тарифа есть дневной лимит запросов. Чтобы не тратить его слишком быстро, подборка использует несколько поисковых запросов и получает подробности только для ограниченного числа результатов. Некоторые жанры или поисковые слова могут вернуть меньше трёх карточек — нажми «Другая подборка» или измени фильтр.
